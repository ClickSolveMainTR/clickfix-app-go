ClickFix is the B2B support platform that gathers all of your customer communication in one inbox. This documentation has four sections, reachable from the left menu or with `Ctrl K` search. The buttons at the top of every page copy it as Markdown or open it in ChatGPT / Claude; everything is also published at [`/en/llms.txt`](/en/llms.txt) and [`/en/llms-full.txt`](/en/llms-full.txt).

## Getting started [#get-started]

- [Getting started with ClickFix](/docs/getting-started?lang=en): account, organization, team, first channel and the **right setup order** (introduce the customer → connect your system → teach the AI → knowledge base → automation).
- [Inbox basics](/docs/inbox?lang=en): views, statuses, assignment, the verified customer badge, custom fields and screen context.
- [Channels overview](/docs/channels?lang=en): supported channels, health, the identity warning, the API channel.
