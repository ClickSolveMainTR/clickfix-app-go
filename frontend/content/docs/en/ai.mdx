AI works in two ways in ClickFix:

- **AI agent**: triages customer conversations, drafts replies grounded in your knowledge base, or sends the reply itself under the conditions you choose.
- **Copilot**: works next to the agent in the inbox; suggests replies, summarizes and edits text.

AI usage is charged against the AI credits in your plan. When credits run out, the agent hands conversations over to a human.

Configure the agent under **Organization → AI**. The page has four tabs: **Agent**, **Procedures**, **Tools** and **Run log**.

## Mode [#mode]

| Mode             | What it does                                                                                                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Off              | The agent writes no replies. With triage on, only topic, priority and a summary are extracted.                                                                               |
| Summary only     | Every new message is triaged and summarized for agents; nothing is sent to the customer.                                                                                     |
| Draft + approval | The agent drafts a reply grounded in the knowledge base; an agent approves and sends it.                                                                                     |
| Autonomous       | Sends the reply itself when it passes the confidence threshold and can cite a source; otherwise hands over to a human with a summary. Stays silent once a human has replied. |

Mode changes apply immediately. If you're new, we recommend starting with **Draft + approval** and moving to autonomous once you're happy with the reply quality.

## Behavior [#behavior]

- **Automatic triage**: extracts the language, intent, category, sentiment and urgency of incoming messages.
- **Persona and tone**: your brand voice and style preferences. This text can't override safety rules.
- **Confidence threshold**: in autonomous mode a reply is sent only when the model's confidence is above this value; otherwise it waits as a draft and is handed to a human.
- **Handoff keywords**: if a customer message contains one of these words (e.g. "agent"), the agent hands over to a human right away.
- **Draft band in the conversation**: when the agent drafts a reply, an "The AI agent drafted a reply" band appears above the composer; it shows up live as soon as the job finishes, no reload needed. When the agent is unsure and hands the conversation over, the model's text (if any) appears labelled **"Unsourced suggestion, please check"**. In both cases nothing reaches the customer until you edit and send it. The band is shown only to members who can reply in the conversation (and so use Copilot), and disappears once a teammate replies after the draft.

## Scope and working hours [#scope-and-working-hours]

- **Channels**: the agent only works on the selected channel types. With none selected it never steps in.
- **Categories**: when set, the agent only replies autonomously in conversations triaged into one of these categories.
- **Reply language**, **Time zone**, **Days** and **Working hours**.

You can also switch the agent on or off per channel with the **AI agent** option in each channel's **Settings**.

## Knowledge source [#knowledge-source]

The agent grounds customer-facing replies in the **public**, **published** articles of your knowledge base. Write your frequent questions as articles for better answers. See [Knowledge base](/docs/knowledge-base?lang=en).

## Procedures [#procedures]

A procedure is the steps the agent follows for a specific customer intent. For a refund request, for example: ask for the order number first, call the order tool, hand over to a human if more than 14 days have passed.

1. Start with **Procedures → New procedure**.
2. Enter the **Intent** exactly as triage produces it (e.g. `refund_request`) and pick the language. Intent and language can't be changed later.
3. Write the title and steps, save, then publish.

Only the published version is used. A procedure can't grant the agent new tools and can't override safety rules.

## Tools [#tools]

**Built-in tools** come with every organization and only work inside the related conversation:

| Tool                   | What it does                                          |
| ---------------------- | ----------------------------------------------------- |
| `lookup_contact`       | Reads the contact's details in the conversation       |
| `conversation_history` | Reads the conversation's public message history       |
| `knowledge_search`     | Searches published knowledge base articles            |
| `create_note`          | Adds an internal note (with agent approval)           |
| `set_status`           | Changes the conversation status (with agent approval) |

**Organization tools (HTTP)** turn an endpoint in your own system into a tool the agent can call (order, license or invoice lookup, for example):

- The agent calls the tool with a JSON `POST` request.
- The **Tool name** starts with a lowercase letter and is 3-50 characters (a-z, 0-9, \_). It can't be changed later.
- The **Daily call limit** is between 1 and 1000.
- With **Needs approval** on, the agent only proposes the call and an agent approves it. Keep it on for tools that change data.
- Credentials are stored encrypted and never shown again. Tools aren't deleted; they're disabled.

## Test chat and run log [#test-chat-and-run-log]

In the **Test chat**, write a message as a customer would and see the agent's reply and the sources it used. Every test is a real run and uses credits.

The **Run log** records every AI run with personal data masked: input, knowledge chunks, tool calls, output, tokens, cost and latency. Use it to see why a reply was given.

## Safety [#safety]

- The agent stops requests that look like prompt injection or would produce unsafe output.
- When daily call, concurrency or budget limits are reached, no new run starts.
- Set how long AI logs are kept under **Privacy & GDPR → Retention**. See [KVKK tools](/docs/data-protection?lang=en).

## Copilot [#copilot]

With a conversation open in the inbox, Copilot can:

- **Suggest a reply** and **Summarize conversation**
- **Rewrite**, **Translate**, **Change tone**, **Shorten** or **Expand** your draft
- **Suggest next step**
- **Ask Copilot**: a free-form question about the conversation

Open the Copilot menu from the reply editor or with keyboard shortcuts (`?` lists them all). Copilot suggestions never reach the customer unless you send them.

## ClickFix Assistant [#assistant]

ClickFix Assistant is the AI helper that opens on every panel page with `⌘J` (`Ctrl+J` on Windows) and **gets things done**; it is separate from the AI agent that answers customers. You write what you want, the assistant asks for what it needs, shows the action on an **approval card**, you approve, it applies the change and verifies the result.

- **Capability cards:** every module registers its capabilities in one registry (reads, actions, tests, page guide). The assistant uses only the capabilities relevant to the page you are on and your permissions. Examples: listing channels and creating an API channel, channel health check, drafting, dry-running and saving a workflow, automation rules, SLA policies and working hours, inviting members and assigning teams, turning AI on, widget setup, webhook subscriptions and test deliveries, creating API keys (with step-up).
- **Page state:** on the page where you open it, the assistant says what can be done there and what you left undone ("no identity secret", "AI is off on this channel"), following the same order as the setup wizard. It runs the test of a setting from inside the drawer (email channel test send, webhook test delivery, SLA rule dry run).
- **Approval card:** an editable parameter form, the dry-run result and a verification step after applying. Destructive actions (revoking a key, deleting a rule) are always confirmed; secrets never reach the chat history or logs; the assistant cannot exceed your permissions, every action is re-checked on the server.
- **Files and links:** share your own API documentation or a link; the assistant reads it and, for example, proposes concepts and endpoints for the [Connect your system](/docs/integration-guide/system-binding?lang=en) screen.
- **Navigation:** when it says "go to this page" it goes there on approval and highlights the relevant field.
- **Surfaces:** the panel drawer, the mobile app and (for verified members only) the support widget. In the widget only reads, navigation and a few safe actions are available.
- **MCP tools:** the same capability registry is exposed to clients such as Claude and Cursor through the [MCP server](/docs/mcp-integrations?lang=en#mcp); there are no two catalogs. Capabilities that carry secrets or are destructive are not on MCP.
- **Limits:** several tool calls in one turn are processed in order; when the turn limit is reached the assistant answers with the results so far; long answers are not cut off but continued automatically (at most two continuations, with a "shortened" note); after using a tool it always produces text. The daily assistant allowance depends on your plan and is shown in the drawer.

The assistant cites its sources in every answer and connects you to our support team when needed. Every page also has a step-by-step **guided tour**.

## One working-hours source and the instant reply [#working-hours-and-instant-reply]

The AI agent's "we are out of office" text, the widget's online/offline state and the SLA timers feed from **one working-hours source**: **Organization → SLA and working hours**. The days and hours on this page's **Scope** tab narrow the range in which the agent replies; they do not change the source.

In every mode (AI, agent, mixed) a new conversation written during working hours gets a "received, estimated time" acknowledgement within 10 seconds; when the AI hands over to a human it tells the customer. The texts live under **Automation → Welcome**. Details: [Automation](/docs/automation?lang=en#instant-reply).

## AI and system binding [#ai-and-system-binding]

The concepts (Invoice, Order, Licence…) and actions ("resend the invoice") you define under **Integrations → Connect your system** feed the AI playbooks: the agent reads the concept from your system with the customer's **external id**, follows the playbook step and performs the action (per its approval rule). No procedure or HTTP tool needs to be defined; a playbook written in plain sentences matches intents by AI classification, not keywords. The **Try as this customer** preview shows the context the agent sees for that customer. Setup: [Connect your system](/docs/integration-guide/system-binding?lang=en).

## AI during set-up [#ai-during-set-up]

When you open a new organization, the set-up wizard can use your website and a few answers to suggest teams, SLAs, canned replies, starter articles and the agent's persona. See [Getting started](/docs/getting-started?lang=en).

## FAQ [#faq]

**What is the difference between the AI agent and ClickFix Assistant?** The agent talks to customers (widget, WhatsApp, email…); the Assistant talks to you, sets up the panel and tests it. They are separate settings and use separate credits / allowances.

**How does the agent know the customer's plan or invoice?** [Custom fields](/docs/integration-guide/custom-fields?lang=en) (those marked visible to AI), [screen context](/docs/integration-guide/events?lang=en) and the concepts read from your system through [Connect your system](/docs/integration-guide/system-binding?lang=en) enter the agent's input. Fields marked sensitive never reach the AI.

**What if the agent says something wrong?** Below the confidence threshold it waits as a draft; handover keywords pass the conversation to an agent at once; every run is logged and can be quality-reviewed.

**What happens when credits run out?** The agent hands new conversations to agents, Copilot and the Assistant switch off; existing drafts are kept.
