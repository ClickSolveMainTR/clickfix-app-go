ClickFix has server SDKs for Go and Node.js and a UI-free widget client for React. The SDKs handle authentication, bounded retries (including `Retry-After`), pagination and webhook signature verification.

<Callout title="Packages">
  `npm install @clickfix/node` (0.1.0, Node 22+), `npm install
  @clickfix/react-widget` (0.1.0, React 18+) and `go get
  github.com/ClickSolveMainTR/clickfix-app-go/sdks/go@v0.1.0`. The end-to-end
  setup order with verified samples at every step: [Integration
  guide](/docs/integration-guide?lang=en). The [examples without an
  SDK](#without-an-sdk) below do the same work over plain HTTP; every endpoint
  in the [API reference](/docs/api-reference/conversations?lang=en) also ships
  ready requests for curl, JavaScript, Python and Go.
</Callout>

Use `https://api.getclickfix.com` as the base URL (without `/v1`). Keep API keys on your server; never put them in browser code. Creating keys and scopes: [API](/docs/api?lang=en).

## Create a client and send a request [#create-a-client]

For writes, pass a stable `Idempotency-Key` that identifies the operation (e.g. an order number) and send the same value when retrying.

```ts tab="Node.js"
import { createClient } from "@clickfix/node";

const client = createClient({
  baseURL: "https://api.getclickfix.com",
  apiKey: process.env.CLICKFIX_API_KEY!,
});

const created = await client.request(
  "/v1/public-api/conversations",
  "post",
  {
    contact_uuid: contactUUID,
    inbox_uuid: inboxUUID,
    subject: "Delivery question",
  },
  { idempotencyKey: "order-42-support", signal: AbortSignal.timeout(30_000) },
);
```

```go tab="Go"
client, err := clickfix.New("https://api.getclickfix.com", os.Getenv("CLICKFIX_API_KEY"))
if err != nil {
	log.Fatal(err)
}
res, err := client.GetV1PublicApiContactsWithResponse(ctx, &clickfix.GetV1PublicApiContactsParams{})
```

On error responses the Node.js client throws an `APIError` with the status, code, request ID and details. GET requests and keyed writes are tried at most three times by default (exponential backoff, bounded `Retry-After`); unkeyed writes are never retried. The Go client adds a 30-second HTTP timeout and the same retry rule.

The API stores completed write responses, including errors: retrying with the same key cannot turn a stored failure into success. Use a new key for corrected input.

## Pagination [#pagination]

```ts tab="Node.js"
import { paginate } from "@clickfix/node";

for await (const contact of paginate(async (limit, offset) => {
  const envelope = await client.request(
    "/v1/public-api/contacts",
    "get",
    undefined,
    {
      query: { limit, offset },
    },
  );
  // Validate envelope.data with your own schema and return {items, total, limit, offset}.
  return validateContactPage(envelope.data);
})) {
  await consume(contact);
}
```

```go tab="Go"
type Contact struct {
	UUID string `json:"uuid"`
	Name string `json:"name"`
}

err = clickfix.Iterate(ctx,
	func(ctx context.Context, limit, offset int) (clickfix.Page[Contact], error) {
		return clickfix.ListPage[Contact](ctx, client, "contacts", limit, offset)
	},
	func(contact Contact) bool { /* process */ return true },
)
```

Offset pagination is for snapshots; concurrent inserts can shift pages. Deduplicate UUIDs when syncing, and use the [trigger cursor](/docs/mcp-integrations?lang=en) for incremental sync.

## Webhook signature and identity hash [#webhook-signature]

```ts tab="Node.js"
import { identityHash, verifyWebhook } from "@clickfix/node";

const valid = verifyWebhook(
  secret,
  headers.timestamp,
  headers.signature,
  rawBody,
);

// user_hash for a signed-in user of the web widget
const userHash = identityHash(identitySecret, authenticatedUser.id);
```

```go tab="Go"
err = clickfix.VerifyWebhook(secret,
	r.Header.Get("ClickFix-Webhook-Timestamp"),
	r.Header.Get("ClickFix-Webhook-Signature"), rawBody, time.Now(), 5*time.Minute)

userHash := clickfix.IdentityHash(identitySecret, userID)
```

Verify the signature on the raw body before parsing JSON, and store and deduplicate `ClickFix-Webhook-Id` before any side effects. Verification without an SDK (Node.js, Python, Go): [Webhooks](/docs/webhooks?lang=en#verifying-the-signature).

## React widget client [#react-widget]

Typed hooks to drive the ready-made messenger (bubble, home, help center) from your own button:

```tsx tab="Ready-made widget"
"use client";
import { useMemo } from "react";
import { useClickFix, useClickFixEvent } from "@clickfix/react-widget";

export function Support({ consent }: { consent: boolean }) {
  const options = useMemo(
    () =>
      consent
        ? {
            appOrigin: "https://getclickfix.com",
            widgetId: "WIDGET_ID",
            hideLauncher: true,
          }
        : null, // null delays loading until consent
    [consent],
  );
  const { ready, unread, open, sdk } = useClickFix(options);
  useClickFixEvent("conversation:ended", (e) => console.log(e.status));

  return (
    <button aria-expanded={open} disabled={!ready} onClick={() => sdk.toggle()}>
      Support {unread || ""}
    </button>
  );
}
```

```tsx tab="Your own UI"
"use client";
import { useEffect, useState } from "react";
import { createWidgetClient, useWidget } from "@clickfix/react-widget";

export function Support() {
  const [client] = useState(() =>
    createWidgetClient({
      publicId: "WIDGET_ID",
      baseURL: "/api", // same-origin proxy on your own site
      onToken: (token) => sessionStorage.setItem("support-token", token),
    }),
  );
  const { visitor } = useWidget(client);

  useEffect(() => {
    const abort = new AbortController();
    void client.init(abort.signal).catch(console.error);
    return () => abort.abort();
  }, [client]);

  return <span>{visitor ? "Ready" : "Connecting"}</span>;
}
```

With the UI-free client you render conversations and messages yourself:

```ts
await client.identify({ user_id: user.id, user_hash: serverProvidedHmac });
const { items } = await client.conversations();
await client.createConversation({
  text: "Hello",
  client_id: crypto.randomUUID(),
});
await client.sendMessage(
  conversationUUID,
  { text: "Photo", client_id: stableMessageUUID },
  file,
);
await client.markRead(conversationUUID);
```

`user_hash` is produced on your server; never send the identity secret to the browser. Widget commands and events: [Web widget](/docs/web-widget?lang=en#javascript-api).

## Requests without an SDK [#without-an-sdk]

```bash tab="curl"
curl -X POST "https://api.getclickfix.com/v1/public-api/conversations/CONVERSATION_UUID/messages" \
  -H "Authorization: Bearer $CLICKFIX_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: order-1042-note" \
  -d '{ "content": "The order has shipped.", "private": true }'
```

```ts tab="fetch"
const res = await fetch(
  "https://api.getclickfix.com/v1/public-api/contacts?limit=20",
  {
    headers: { Authorization: `Bearer ${process.env.CLICKFIX_API_KEY}` },
  },
);
const body = await res.json();
if (!body.success) throw new Error(`${body.error.code}: ${body.error.message}`);
```

```python tab="Python"
import os, requests

API = "https://api.getclickfix.com/v1/public-api"
headers = {"Authorization": f"Bearer {os.environ['CLICKFIX_API_KEY']}"}

contacts = requests.get(f"{API}/contacts", params={"limit": 20}, headers=headers, timeout=30).json()

created = requests.post(
    f"{API}/conversations",
    json={"contact_uuid": contact_uuid, "inbox_uuid": inbox_uuid, "subject": "Delivery question"},
    headers={**headers, "Idempotency-Key": "order-1042-support"},
    timeout=30,
).json()
```

On `429 RATE_LIMITED`, wait for `Retry-After` and retry with the same `Idempotency-Key`; don't retry `400`, `401` and `403`.
