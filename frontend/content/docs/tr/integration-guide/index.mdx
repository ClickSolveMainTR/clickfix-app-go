Bu kılavuz, panelde **Kurulum** sihirbazının izlediği sırayla, kendi ürününüzü ClickFix'e bağlamak için yazmanız gereken her şeyi adım adım anlatır. Her adım kendi sayfasındadır ve her adımda beş örnek vardır: tarayıcıdaki **widget** (JavaScript), **Node.js** (`@getclickfix/node`), **Go** (`github.com/ClickSolveMainTR/clickfix-sdks/go`), **PHP** (`clickfix/sdk`) ve **curl**. Örnekler her sürümde bir test API'sine karşı çalıştırılarak doğrulanır; burada gördüğünüz kod, testten geçen koddur. Çalışan tam uygulamalar (Express, Next.js, React Native, Expo, Flutter, Go, PHP, Laravel, curl) için [`clickfix-examples`](https://github.com/ClickSolveMainTR/clickfix-examples) deposuna bakın.

## Başlamadan önce [#before-you-start]

| Gereken                                 | Nereden                                              | Nerede kullanılır                                                                                                               |
| --------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **API anahtarı** (`cf_sk_…`)            | Organizasyon → API ve otomasyonlar → API anahtarları | Sunucunuzdan yapılan tüm çağrılar (`Authorization: Bearer`)                                                                     |
| **Widget kimlik anahtarı**              | Web widget → Güvenlik → Kimlik doğrulama             | `user_hash` hesaplamak için (kullanıcı + firma kimliği), yalnız sunucuda                                                        |
| **Widget kimliği** (`WIDGET_ID`)        | Web widget → Kurulum                                 | `widget.js` ve mobil webview adresi                                                                                             |
| **API kanalı kimliği ve imza anahtarı** | Kanallar → Kanal ekle → API                          | Yalnız kendi sohbet uygulamanızı kanal olarak bağlıyorsanız                                                                     |
| **Uygulama anahtarı** (mobil)           | Web widget → Gelişmiş → Mobil uygulamalar            | Widget API'sini webview'siz çağıran uygulamalar (`@getclickfix/react-native`, `@getclickfix/expo`, `@getclickfix/visitor-core`) |

Temel adres `https://api.getclickfix.com` (sonuna `/v1` eklemeyin). Yazma isteklerinde `Idempotency-Key` zorunludur. Anahtarlar tarayıcıya ve mobil uygulamaya girmez. Yanıt zarfı, hata kodları ve hız sınırları: [API](/docs/api).
