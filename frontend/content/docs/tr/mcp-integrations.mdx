Bu sayfa ClickFix'i dış araçlarla nasıl bağlayacağınızı anlatır:

- **Zapier, Make ve n8n**: REST hook abonelikleri, tetikleyici yoklama ve API eylemleri.
- **Uygulamalar**: Kendi web uygulamanızı veya galerideki araçları konuşma kenar çubuğunda, kişi panelinde veya menüde açmak.

## Zapier, Make ve n8n [#zapier-make-and-n8n]

Otomasyon araçları ClickFix'in herkese açık API'sini kullanır. Hazırlık:

1. **Organizasyon → API ve otomasyonlar** sayfasında bir API anahtarı oluşturun. Otomasyon araçları için genellikle şu kapsamlar yeterlidir: `triggers:read`, `webhooks:write`, `conversations:write`, `contacts:write`.
2. Temel adres: `https://api.getclickfix.com/v1/public-api`
3. Her istekte `Authorization: Bearer cf_sk_...` başlığını gönderin.
4. Tüm yazma isteklerinde benzersiz bir `Idempotency-Key` başlığı kullanın; tekrar denemede aynısını gönderin.

### Tetikleyici olaylar [#trigger-events]

| Olay                     | Ne zaman                            |
| ------------------------ | ----------------------------------- |
| `conversation.created`   | Yeni konuşma açıldığında            |
| `conversation.resolved`  | Konuşma çözüldüğünde                |
| `contact.created`        | Yeni kişi oluştuğunda               |
| `csat.submitted`         | Müşteri memnuniyet puanı verdiğinde |
| `conversation.tag_added` | Konuşmaya etiket eklendiğinde       |

### REST hook (anlık) [#rest-hooks-instant]

Akış açıldığında abone olun, kapandığında aboneliği silin:

| İşlem             | Uç nokta                       | Kapsam           |
| ----------------- | ------------------------------ | ---------------- |
| Abone ol          | `POST /subscriptions`          | `webhooks:write` |
| Abonelikten ayrıl | `DELETE /subscriptions/{uuid}` | `webhooks:write` |

Abone olma gövdesi:

```json
{
  "name": "Zap: yeni konuşma",
  "url": "https://hooks.ornek.com/receiver",
  "events": ["conversation.created"],
  "enabled": true
}
```

Yanıttaki `data.uuid` değerini ayrılmak için, `data.secret` değerini [imza doğrulama](/docs/webhooks) için saklayın. Etkin abonelikler panelde **REST hook abonelikleri** sekmesinde görünür; buradan silinen aboneliğe gönderim durur.

### Tetikleyici yoklama [#trigger-polling]

REST hook kullanamayan araçlar için yoklama:

```bash
curl "https://api.getclickfix.com/v1/public-api/triggers?event=conversation.created&cursor=0" \
  -H "Authorization: Bearer cf_sk_..."
```

- Her sayfa en fazla 100 öğe içerir ve organizasyon içindeki sıraya göre artan düzendedir.
- İşledikten sonra `data.next_cursor` değerini saklayın ve bir sonraki çağrıda kullanın. `has_more` doğru olduğu sürece devam edin.
- Öğeler olay kimliği, olay adı, ilgili kaydın kimliği ve olay zamanını içerir. Ayrıntıları normal API ile okuyun.
- Geçmiş 30 gün tutulur. `410 CURSOR_EXPIRED` yanıtı alırsanız verilerinizi yeniden eşitleyip `cursor=0` ile başlayın.

### Araç bazında [#per-tool]

- **Zapier**: Abone ol / ayrıl ve liste için yukarıdaki uç noktaları bir REST hook tetikleyicisine bağlayın; eylemler için HTTP isteklerini kullanın.
- **Make**: **Custom webhook** modülüyle aynı abone ol / ayrıl isteklerini ve HTTP eylemlerini kullanın.
- **n8n**: HTTP Request düğümüyle aynı uç noktaları çağırabilirsiniz. Bir topluluk düğümü paketlemek isterseniz [n8n düğüm tanımı](/docs/n8n-node) sayfasındaki düğüm ve kimlik bilgisi tanımlarını kullanın.

ClickFix'in Zapier, Make veya n8n mağazalarında yayımlanmış resmi bir uygulaması henüz yoktur; bağlantılar yukarıdaki genel HTTP / webhook modülleriyle kurulur.

## Uygulamalar [#apps]

Kendi web uygulamanızı (sipariş paneli, CRM kaydı, fatura geçmişi gibi) konuşma kenar çubuğunda, kişi panelinde veya menüde açabilir; galeriden Calendly, Uptime Kuma, Metabase gibi araçları tek tıkla kurabilirsiniz. Uygulamalar **Organizasyon → Uygulama yönetimi** sayfasından yönetilir.

Bağlam belirteci, imza doğrulama, mesajlar, tema ve yayınlama adımları için [Kendi uygulamanızı yapın](/docs/apps) rehberine bakın.

## ClickFix MCP sunucusu [#mcp]

ClickFix, Claude, Cursor ve MCP destekleyen diğer istemcilerin bağlanabildiği bir **MCP sunucusu** sunar. Araçlar, [ClickFix Asistan](/docs/ai#assistant)'ın kullandığı yetenek defterinden gelir; iki ayrı katalog yoktur. Bağlantı OAuth ile kurulur (istemci, organizasyon üyesi olarak yetkilendirilir) ve her araç üyenin yetkisiyle sınırlıdır. Gizli alan taşıyan (anahtar üretme) ve yıkıcı yetenekler MCP'de yoktur; yazma araçları onay gerektirir.

Örnek araçlar: `channels_list`, `channels_api_sample_request`, `workflows_list`, `workflows_reference`, `workflows_dry_run`, `automations_list`, `automations_dry_run`, `sla_list`, `sla_check`, `teams_list`, `members_list`, `webhooks_list`, `widget_install_code`, `integrations_list`, `integrations_system_describe`, `integrations_concepts_lookup`, `search_conversations`, `get_conversation`, `list_contacts`, `ai_status`. Sunucu adresi ve kurulum adımları **Organizasyon → API ve otomasyonlar → MCP** sayfasındadır.

## Sık sorulanlar [#faq]

**Zapier için REST hook mu, yoklama mı?** Zapier ve Make anlık tetikleyici için REST hook aboneliğini (`POST /subscriptions`) kullanır; n8n ve zamanlanmış işler için `GET /triggers` imleçli yoklama yeter.

**MCP ile ne yapamam?** Anahtar üretemez, kayıt silemez, gizli değer okuyamazsınız; bunlar panelde (ya da Asistan onay kartında) kalır.
