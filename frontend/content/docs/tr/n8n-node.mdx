n8n'de ClickFix'i en kolay **HTTP Request** düğümüyle bağlarsınız; uç noktalar [Zapier, Make ve n8n](/docs/mcp-integrations#per-tool) sayfasındadır. Kendi topluluk düğümünüzü paketlemek isterseniz bu sayfadaki iki tanımı başlangıç noktası olarak kullanabilirsiniz.

## Ne içerir [#what-it-contains]

- `ClickFix.description.json`: n8n'in `INodeTypeDescription` biçimine uyan bildirime dayalı (declarative) düğüm tanımı. Konuşma oluşturma, iç not ekleme, kişi güncelleme, tetikleyici sorgulama ve REST hook aboneliği işlemlerini içerir.
- `ClickFix.credentials.json`: `Authorization: Bearer cf_sk_…` başlığını ekleyen genel kimlik bilgisi tanımı.

Paketinizde bunları düğümün `description` alanına ve kimlik bilgisinin `properties` / `authenticate` alanlarına yükleyin; TypeScript sarmalayıcısını, paket bilgilerini ve simgeyi siz eklersiniz. Biçim, [n8n'in resmi bildirime dayalı düğüm rehberini](https://docs.n8n.io/integrations/creating-nodes/build/declarative-style-node/) izler.

## Kurulum notları [#setup-notes]

- **API Base URL** alanına `https://api.getclickfix.com` yazın (sonuna `/v1` eklemeyin). Tanımdaki `https://support.example.com` yalnızca bir yer tutucudur.
- **API Key** alanına **API ve otomasyonlar → API anahtarları** sayfasında oluşturduğunuz anahtarı girin. İhtiyaç duyulan kapsamlar: `triggers:read`, `webhooks:write`, `conversations:write`, `contacts:write`.
- Tüm yazma işlemleri bir `Idempotency-Key` başlığı ister; tekrar denemelerde aynı değeri gönderin.
- REST hook tetikleyici düğümü, aboneliğin `uuid` ve `secret` değerlerini saklamalı, devre dışı bırakılınca aboneliği silmeli ve [webhook imzasını](/docs/webhooks) doğrulamalıdır.
- ClickFix'in n8n pazarında yayımlanmış resmi bir düğümü henüz yoktur.

## Tanımlar [#definitions]

Her sekme bir dosyadır; sağ üstteki düğmeyle kopyalayın.

```json tab="ClickFix.credentials.json"
{
  "name": "clickFixApi",
  "displayName": "ClickFix API",
  "properties": [
    {
      "displayName": "API Base URL",
      "name": "baseUrl",
      "type": "string",
      "default": "https://support.example.com",
      "required": true
    },
    {
      "displayName": "API Key",
      "name": "apiKey",
      "type": "string",
      "typeOptions": {
        "password": true
      },
      "default": "",
      "required": true
    }
  ],
  "authenticate": {
    "type": "generic",
    "properties": {
      "headers": {
        "Authorization": "={{\"Bearer \" + $credentials.apiKey}}"
      }
    }
  }
}
```
