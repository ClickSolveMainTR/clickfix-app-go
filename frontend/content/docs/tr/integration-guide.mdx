Bu sayfa tek entegrasyon kılavuzudur: panelde **Kurulum** sihirbazının izlediği sırayla, kendi ürününüzü ClickFix'e bağlamak için yazmanız gereken her şeyi anlatır. Her adımda dört örnek vardır: tarayıcıdaki **widget** (JavaScript), **Node.js** (`@clickfix/node`), **Go** (`sdks/go` modülü) ve **curl**. Örnekler repodaki [`sdks/examples`](https://github.com/ClickSolveMainTR/clickfix-app-go/tree/main/sdks/examples) klasöründen gelir ve her sürümde çalıştırılarak doğrulanır; burada gördüğünüz kod, testten geçen koddur.

## Başlamadan önce [#before-you-start]

| Gereken                                 | Nereden                                              | Nerede kullanılır                                           |
| --------------------------------------- | ---------------------------------------------------- | ----------------------------------------------------------- |
| **API anahtarı** (`cf_sk_…`)            | Organizasyon → API ve otomasyonlar → API anahtarları | Sunucunuzdan yapılan tüm çağrılar (`Authorization: Bearer`) |
| **Widget kimlik anahtarı**              | Web widget → Güvenlik → Kimlik doğrulama             | `user_hash` hesaplamak için, yalnız sunucuda                |
| **Widget kimliği** (`WIDGET_ID`)        | Web widget → Kurulum                                 | `widget.js` ve mobil webview adresi                         |
| **API kanalı kimliği ve imza anahtarı** | Kanallar → Kanal ekle → API                          | Yalnız kendi sohbet uygulamanızı kanal olarak bağlıyorsanız |

Temel adres `https://api.getclickfix.com` (sonuna `/v1` eklemeyin). Yazma isteklerinde `Idempotency-Key` zorunludur. Anahtarlar tarayıcıya ve mobil uygulamaya girmez. Yanıt zarfı, hata kodları ve hız sınırları: [API](/docs/api).

## 1. Kimlik doğrulama: `user_hash` [#identity]

Giriş yapmış kullanıcıyı widget'a kanıtlı biçimde tanıtmanın tek yolu `user_hash` değeridir:

```text
user_hash = hex(HMAC-SHA256(widget_kimlik_anahtari, user_id))
```

`user_id` kullanıcının **sizin** sisteminizdeki kimliğidir ve bir sonraki bölümdeki dış kimliğin kendisidir. Değer **yalnız sunucunuzda** hesaplanır; sitenize ve mobil uygulamanıza anahtar değil, hazır `user_hash` gider. Geçerli `user_hash` ile doğrulanan kişi panelde **Doğrulanmış** rozeti alır; anonim geçmişi aynı kişiye taşınır. Reddedilen `identify` çağrısında widget çalışmaya devam eder ama kullanıcı anonim kalır ve `error` olayı `WIDGET_IDENTITY_DISABLED` (anahtar üretilmemiş) ya da `WIDGET_IDENTITY_INVALID` (eşleşmiyor) kodunu verir.

{/* example: widget/01-identify.js */}

```js tab="Widget"
// Adım 1: sunucunuzdan aldığınız user_hash ile giriş yapmış kullanıcıyı tanıtın.
// @ts-check
ClickFix("boot", { widgetId: "WIDGET_ID", locale: "tr" });

fetch("/api/support-session") // sizin ucunuz: { user_id, user_hash } döner
  .then((r) => r.json())
  .then((session) =>
    ClickFix("identify", {
      user_id: session.user_id, // kişinin dış kimliği
      user_hash: session.user_hash, // hex(HMAC-SHA256(anahtar, user_id)), sunucuda
      name: "Ayşe Yılmaz",
      email: "ayse@example.com",
    }),
  );

ClickFix("on", "error", (e) => {
  if (e.code === "WIDGET_IDENTITY_INVALID")
    console.warn("user_hash eşleşmedi:", e.message);
});
```

{/* example: node/01-user-hash.ts */}

```ts tab="Node.js"
// Adım 1: user_hash sunucuda hesaplanır ve giriş yapmış kullanıcıya verilir.
import { identityHash } from "@clickfix/node";

// Panel > Web widget > Güvenlik > Kimlik doğrulama anahtarı (bir kez gösterilir)
const secret = process.env.CLICKFIX_IDENTITY_SECRET!;

// Oturum açmış kullanıcının sizin sisteminizdeki kimliği (dış kimlik)
export function userHashFor(userId: string): string {
  return identityHash(secret, userId);
}

// Örnek: /api/support-session uç noktanız bunu döner, tarayıcı identify'a verir
console.log(
  JSON.stringify({ user_id: "1001", user_hash: userHashFor("1001") }),
);
```

{/* example: go/user_hash.go */}

```go tab="Go"
package main

import (
	"context"
	"encoding/json"
	"os"

	clickfix "github.com/ClickSolveMainTR/clickfix-sdks/go"
)

// Adım 1: user_hash sunucuda hesaplanır; anahtar tarayıcıya ve uygulamaya gitmez.
func userHash(ctx context.Context) error {
	secret := os.Getenv("CLICKFIX_IDENTITY_SECRET") // Panel > Web widget > Güvenlik
	userID := "1001"                                // kullanıcının sizin sisteminizdeki kimliği
	hash := clickfix.IdentityHash(secret, userID)
	return json.NewEncoder(os.Stdout).Encode(map[string]string{"user_id": userID, "user_hash": hash})
}
```

{/* example: curl/01-user-hash.sh */}

## 2. Dış kimlik: kişi ve şirket [#external-id]

Kendi sisteminizdeki numaralar ClickFix'te **dış kimlik** (`external_id`) olarak tutulur. Kişi ve şirket dış kimlikleri **ayrı alanlardır**, birbirinden bağımsızdır ve organizasyon içinde tekildir:

| Kayıt  | API alanı     | Widget `identify` karşılığı | Sistem bağlamada        |
| ------ | ------------- | --------------------------- | ----------------------- |
| Kişi   | `external_id` | `user_id`                   | `{external_id}`         |
| Şirket | `external_id` | `company.id`                | `{company_external_id}` |

`PUT /v1/public-api/contacts/by-external-id` kişiyi dış kimliğiyle oluşturur ya da günceller (`201` oluşturuldu, `200` güncellendi). Eşleşme yalnız dış kimlikle yapılır; e-posta ya da telefon üzerinden başka bir kişi devralınmaz. Başka kişide olan bir kimlik `409 EXTERNAL_ID_EXISTS` döner. Kişiyi önce API ile açıp sonra kullanıcı `identify` ile gelirse yeni kişi açılmaz, aynı kişiye bağlanır; temsilcinin müşteri siteye girmeden açtığı konuşma (`contact_external_id` ile) kullanıcı oturum açınca widget'ta görünür.

{/* example: widget/02-external-id.js */}

```js tab="Widget"
// Adım 2: kişi ve şirket için ayrı dış kimlik. user_id kişinin, company.id şirketin.
// @ts-check
ClickFix("identify", {
  user_id: "1001", // API: contacts.external_id
  user_hash: "SUNUCUDA_HESAPLANAN",
  company: { id: "F-77", name: "Acme A.Ş.", domain: "acme.com.tr" }, // API: companies.external_id
});
ClickFix("on", "identify", ({ verified }) =>
  console.log("doğrulandı:", verified),
);
```

{/* example: node/02-external-id.ts */}

```ts tab="Node.js"
// Adım 2: kişiyi dış kimliğiyle oluştur/güncelle, şirketi dış kimliğiyle bul.
import { createClient } from "@clickfix/node";

const client = createClient({
  baseURL: process.env.CLICKFIX_BASE_URL!, // https://api.getclickfix.com
  apiKey: process.env.CLICKFIX_API_KEY!, // contacts:read, contacts:write, companies:read
});

// Aynı dış kimlikle ikinci çağrı yeni kişi açmaz, günceller (200); ilki 201 döner.
const contact = await client.request(
  "/v1/public-api/contacts/by-external-id",
  "put",
  { external_id: "1001", name: "Ayşe Yılmaz", email: "ayse@example.com" },
  { idempotencyKey: `user-1001-${Date.now()}` },
);

// Şirketin dış kimliği kişininkinden ayrıdır (widget: company.id).
const companies = await client.request(
  "/v1/public-api/companies",
  "get",
  undefined,
  { query: { external_id: "F-77" } },
);

console.log(
  JSON.stringify({ contact: contact.data, companies: companies.data }),
);
```

{/* example: go/external_id.go */}

```go tab="Go"
package main

import (
	"context"
	"encoding/json"
	"fmt"
	"os"
	"time"

	clickfix "github.com/ClickSolveMainTR/clickfix-sdks/go"
)

// Adım 2: kişiyi dış kimliğiyle oluştur/güncelle, şirketi dış kimliğiyle bul.
func externalID(ctx context.Context) error {
	client, err := clickfix.New(os.Getenv("CLICKFIX_BASE_URL"), os.Getenv("CLICKFIX_API_KEY"))
	if err != nil {
		return err
	}
	name, email := "Ayşe Yılmaz", "ayse@example.com"
	key := fmt.Sprintf("user-1001-%d", time.Now().UnixNano())
	res, err := client.PutV1PublicApiContactByExternalIdWithResponse(ctx,
		&clickfix.PutV1PublicApiContactByExternalIdParams{IdempotencyKey: key},
		clickfix.PutV1PublicApiContactByExternalIdJSONRequestBody{ExternalId: "1001", Name: &name, Email: &email})
	if err != nil {
		return err
	}
	if res.StatusCode() != 200 && res.StatusCode() != 201 { // 200 güncellendi, 201 oluşturuldu
		return fmt.Errorf("clickfix: HTTP %d", res.StatusCode())
	}
	ext := "F-77" // şirketin dış kimliği (widget identify: company.id)
	companies, err := client.GetV1PublicApiCompaniesWithResponse(ctx, &clickfix.GetV1PublicApiCompaniesParams{ExternalId: &ext})
	if err != nil {
		return err
	}
	return json.NewEncoder(os.Stdout).Encode(map[string]any{"contact": res.StatusCode(), "companies": companies.StatusCode()})
}
```

{/* example: curl/02-external-id.sh */}

```bash tab="curl"
# Adım 2: kişiyi dış kimliğiyle oluştur/güncelle (201 oluşturuldu, 200 güncellendi).
curl -sS --fail-with-body -X PUT "$CLICKFIX_BASE_URL/v1/public-api/contacts/by-external-id" \
  -H "Authorization: Bearer $CLICKFIX_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: user-1001-$(date +%s)" \
  -d '{ "external_id": "1001", "name": "Ayşe Yılmaz", "email": "ayse@example.com" }'

# Şirketi kendi dış kimliğiyle bul (kişi dış kimliğinden ayrıdır).
curl -sS --fail-with-body "$CLICKFIX_BASE_URL/v1/public-api/companies?external_id=F-77" \
  -H "Authorization: Bearer $CLICKFIX_API_KEY"
```

Konuşma ve kişi yanıtlarındaki `identity_state` alanı `verified`, `anonymous` ya da `self_named` değerini alır; webhook olayları `contact_external_id`, `contact_verified`, `company_uuid` ve `company_external_id` taşır, böylece kendi kaydınızı ek istek atmadan eşleştirirsiniz.

## 3. Özel alanlar [#custom-fields]

Özel alanı **Ayarlar → Özel alanlar** altında bir kez tanımlarsınız; tanımlamak tek adımdır. Alanın **anahtarı** neyse, hem API'de `custom_fields` içinde hem widget'ta `setAttributes` / `identify({ attributes })` içinde o anahtarı gönderirsiniz. Değer alanın tipine göre doğrulanır; **liste** alanlarında seçeneğin kimliği ya da etiketi kabul edilir ve kimlik saklanır. Alanın **widget erişimi** anonim ziyaretçinin yazıp yazamayacağını belirler (varsayılan: yalnız doğrulanmış kullanıcı). Tanımsız bir anahtar yok sayılmaz: panelde **tanımsız alan** uyarısı olarak listelenir ve alanı tanımladığınızda kişiye işlenir. Kişi henüz yoksa widget sonucu `pending: true` döner ve değerler ilk mesajla gider.

{/* example: widget/03-custom-fields.js */}

```js tab="Widget"
// Adım 3: özel alanlar. Anahtar panelde tanımlı alanın anahtarıdır; tanımsız
// anahtar "tanımsız alan" uyarısı olarak kalır ve alanı tanımlayınca işlenir.
// @ts-check
ClickFix("setAttributes", {
  plan: "pro",
  seats: 12,
  renewal_date: "2027-01-31",
});
ClickFix("on", "attributes", ({ applied, ignored, pending }) => {
  console.log({ applied, ignored, pending }); // pending: ilk mesajla gönderilecek
});
```

{/* example: node/03-custom-fields.ts */}

```ts tab="Node.js"
// Adım 3: özel alanlar. Alanı panelde tanımlayın (Ayarlar > Özel alanlar);
// anahtarı neyse custom_fields içinde o anahtarla gönderin.
import { createClient } from "@clickfix/node";

const client = createClient({
  baseURL: process.env.CLICKFIX_BASE_URL!,
  apiKey: process.env.CLICKFIX_API_KEY!,
});

const contact = await client.request(
  "/v1/public-api/contacts/by-external-id",
  "put",
  {
    external_id: "1001",
    // Liste alanlarında seçeneğin kimliği ya da etiketi kabul edilir.
    custom_fields: { plan: "pro", seats: 12, renewal_date: "2027-01-31" },
  },
  { idempotencyKey: `user-1001-fields-${Date.now()}` },
);

console.log(JSON.stringify(contact.data));
```

{/* example: go/custom_fields.go */}

```go tab="Go"
package main

import (
	"context"
	"encoding/json"
	"fmt"
	"os"
	"time"

	clickfix "github.com/ClickSolveMainTR/clickfix-sdks/go"
)

// Adım 3: özel alanlar; anahtar panelde tanımladığınız alanın anahtarıdır.
func customFields(ctx context.Context) error {
	client, err := clickfix.New(os.Getenv("CLICKFIX_BASE_URL"), os.Getenv("CLICKFIX_API_KEY"))
	if err != nil {
		return err
	}
	fields := map[string]any{"plan": "pro", "seats": 12, "renewal_date": "2027-01-31"}
	res, err := client.PutV1PublicApiContactByExternalIdWithResponse(ctx,
		&clickfix.PutV1PublicApiContactByExternalIdParams{IdempotencyKey: fmt.Sprintf("user-1001-fields-%d", time.Now().UnixNano())},
		clickfix.PutV1PublicApiContactByExternalIdJSONRequestBody{ExternalId: "1001", CustomFields: &fields})
	if err != nil {
		return err
	}
	if res.StatusCode() != 200 && res.StatusCode() != 201 {
		return fmt.Errorf("clickfix: HTTP %d", res.StatusCode())
	}
	return json.NewEncoder(os.Stdout).Encode(map[string]int{"status": res.StatusCode()})
}
```

## 4. Şirket [#company]

Şirket, widget `identify` çağrısındaki `company` ile oluşur ya da eşleşir: birinci anahtar `company.id` (şirketin dış kimliği), ikinci anahtar `domain`. API'de şirket `GET /v1/public-api/companies?external_id=` ile bulunur; şirket kaydı üzerinde müşteri sağlığı için üç sinyal gönderilir: kullanım (`PUT /company-usage`, 0–100), gelir (`PUT /company-revenue`) ve ürün olayları (`POST /company-events`, bir sonraki bölüm). Şirket her üçünde `company_uuid`, `external_id` ya da `domain` ile seçilir.

{/* example: widget/04-company.js */}

```js tab="Widget"
// Adım 4: şirket identify ile oluşur ya da dış kimliğiyle eşleşir (ikinci anahtar: domain).
// @ts-check
ClickFix("boot", {
  widgetId: "WIDGET_ID",
  user: {
    user_id: "1001",
    user_hash: "SUNUCUDA_HESAPLANAN",
    company: { id: "F-77", name: "Acme A.Ş.", domain: "acme.com.tr" },
  },
});
```

{/* example: node/04-company.ts */}

```ts tab="Node.js"
// Adım 4: şirket. Şirket widget identify (company.id) ile oluşur; API ile

import { createClient } from "@clickfix/node";

const client = createClient({
  baseURL: process.env.CLICKFIX_BASE_URL!,
  apiKey: process.env.CLICKFIX_API_KEY!, // companies:read, health:write

  // İşlemi tanımlayan sabit değer: kendi ölçüm kaydınızın kimliği (örnekte zaman damgası)
  { idempotencyKey: `usage-F-77-${Date.now()}` },
);

console.log(JSON.stringify({ found: found.data, usage: usage.data }));
```

{/* example: go/company.go */}

```go tab="Go"
package main

import (
	"context"
	"encoding/json"
	"fmt"
	"os"
	"time"

	clickfix "github.com/ClickSolveMainTR/clickfix-sdks/go"
)

// Adım 4: şirketi bul ve kullanım sinyali gönder (health:write).
func company(ctx context.Context) error {
	client, err := clickfix.New(os.Getenv("CLICKFIX_BASE_URL"), os.Getenv("CLICKFIX_API_KEY"))
	if err != nil {
		return err
	}
	ext := "F-77"
	found, err := client.GetV1PublicApiCompaniesWithResponse(ctx, &clickfix.GetV1PublicApiCompaniesParams{ExternalId: &ext})
	if err != nil {
		return err
	}
	usage, err := client.PutV1PublicApiCompanyUsageWithResponse(ctx,
		// İşlemi tanımlayan sabit değer: kendi ölçüm kaydınızın kimliği (örnekte zaman damgası)
		&clickfix.PutV1PublicApiCompanyUsageParams{IdempotencyKey: fmt.Sprintf("usage-F-77-%d", time.Now().UnixNano())},
		clickfix.PutV1PublicApiCompanyUsageJSONRequestBody{ExternalId: &ext, Score: 82})
	if err != nil {
		return err
	}
	if usage.StatusCode() != 200 {
		return fmt.Errorf("clickfix: HTTP %d", usage.StatusCode())
	}
	return json.NewEncoder(os.Stdout).Encode(map[string]int{"found": found.StatusCode(), "usage": usage.StatusCode()})
}
```

## 6. Sistem bağlama [#system-binding]

**Entegrasyonlar → Sistemini bağla** ekranı ClickFix'in sizin sisteminizi çağırmasını sağlar; ters yönde bir API değildir. Siz yalnız müşterinin dış kimliğiyle cevap veren bir uç yazarsınız, gerisi panelde kurulur:

1. **Bağlantı:** sisteminizin temel adresi (yalnız herkese açık `https`) ve kimlik doğrulaması (yok, Bearer, özel başlık ya da kullanıcı adı/parola). Gizli değer şifreli saklanır, bir daha gösterilmez, loglarda maskelenir.
2. **Kavramlar:** sisteminizdeki nesneler (Fatura, Sipariş, Lisans…). Her kavram bir özel nesne tipidir.
3. **Kaynak:** kavramın hangi uçtan okunacağı, temel adrese göre: `/customers/{external_id}/invoices`. `{external_id}` müşterinin, `{company_external_id}` firmasının sizin sisteminizdeki kimliğidir; ikisinden biri uçta bulunmalıdır. **Dene** ile gerçek bir kimlikle çağırır, kayıtların cevabın neresinde olduğunu (`items`) ve AI'ın göreceği alanları cevaptan tıklayarak seçersiniz.
4. **İşler:** "Faturayı tekrar gönder" gibi eylemler: yöntem, uç, parametreler, onay gerekip gerekmediği ve kimin kullanabileceği (AI, temsilci, iş akışı).
5. **AI tarifleri:** bir niyet için hangi kavramların okunacağı ve hangi işlerin yapılabileceği.

ClickFix çağrıyı yalnız herkese açık adreslere yapar (iç ağ, yerel ve bulut meta veri adresleri reddedilir), yönlendirme izlemez, cevabı 256 KB ile sınırlar ve organizasyon başına dakikada 60 çağrı yapar. Ucunuzun şekli serbesttir; aşağıdaki örnek, panelde `/customers/{external_id}/invoices` ve kayıt yolu `items` olarak kurulan bir kaynağı karşılar. `curl` örneği panelin **Dene** düğmesinin attığı çağrının aynısıdır.

## 7. API kanalı [#api-channel]

Kendi sohbet uygulamanızı ya da sisteminizi bir **kanal** olarak bağlamak için API kanalı kullanılır; web sitesinde buna gerek yoktur, widget zaten kanaldır. Kanal **Kanallar → Kanal ekle → API** ile kurulur; size gelen adres (`/v1/webhooks/channels/api/{instance}`), bir **imza anahtarı** ve temsilci yanıtlarının gönderileceği adresi girmeniz için bir alan verilir.

- **Müşteri mesajı → ClickFix:** `POST /v1/webhooks/channels/api/{instance}` gövdesi `{ id, sender_id, sender_name?, text, thread_id?, reply_to?, at? }`. İstek API anahtarıyla değil kanalın imza anahtarıyla doğrulanır: `X-ClickFix-Timestamp` (Unix saniye) ve `X-ClickFix-Signature: sha256=` + hex(HMAC-SHA256(imza_anahtarı, timestamp + "." + ham_gövde)). `sender_id` müşterinin sizin sisteminizdeki kimliğidir; aynı `id` bir kez kaydedilir.
- **Temsilci yanıtı → siz:** ClickFix, kanalda tanımladığınız adrese `apiChannelReply` gövdesiyle `POST` atar; aynı imza başlıkları ve mesaj UUID'sini taşıyan `Idempotency-Key` ile. Mesajı kaydettikten sonra `2xx` dönün; `408` ve `429` dışındaki `4xx` kalıcı hata sayılır. Doğrulama [webhook imzasıyla](#webhooks) aynıdır (`v1=` yerine `sha256=`).

package main

import (
	"bytes"
	"context"
	"crypto/hmac"
	"crypto/sha256"
	"encoding/hex"
	"encoding/json"
	"fmt"
	"net/http"
	"os"
	"strconv"
	"time"
)

// Adım 6: API kanalına müşteri mesajı gönder; imza kanalın imza anahtarıyla.
func apiChannel(ctx context.Context) error {
	base, instance, secret := os.Getenv("CLICKFIX_BASE_URL"), os.Getenv("CLICKFIX_CHANNEL_INSTANCE"), os.Getenv("CLICKFIX_CHANNEL_SECRET")
	body, _ := json.Marshal(map[string]string{
		"id":          fmt.Sprintf("msg-%d", time.Now().UnixNano()), // kanal içinde tekil
		"sender_id":   "1001",                                       // müşterinin sizin sisteminizdeki kimliği
		"sender_name": "Ayşe Yılmaz",
		"text":        "Siparişim ne zaman gelir?",
	})
	timestamp := strconv.FormatInt(time.Now().Unix(), 10)
	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write([]byte(timestamp + "."))
	mac.Write(body)
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, base+"/v1/webhooks/channels/api/"+instance, bytes.NewReader(body))
	if err != nil {
		return err
	}
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("X-ClickFix-Timestamp", timestamp)
	req.Header.Set("X-ClickFix-Signature", "sha256="+hex.EncodeToString(mac.Sum(nil)))
	res, err := http.DefaultClient.Do(req)
	if err != nil {
		return err
	}
	defer res.Body.Close()
	if res.StatusCode != http.StatusOK {
		return fmt.Errorf("clickfix: HTTP %d", res.StatusCode)
	}
	return json.NewEncoder(os.Stdout).Encode(map[string]int{"status": res.StatusCode})
}

## 8. Webhook'lar [#webhooks]

Webhook'lar olayları (yeni konuşma, gelen mesaj, kişi güncellemesi, SLA ihlali, memnuniyet…) imzalı `POST` ile size iletir; yoklama gerekmez. Abonelik `webhooks:write` kapsamıyla `POST /v1/public-api/webhooks` ile açılır; yanıttaki `data.secret` yalnız o yanıtta döner. Adres herkese açık `https` olmalıdır. Her teslimat `ClickFix-Webhook-Id`, `ClickFix-Webhook-Event`, `ClickFix-Webhook-Timestamp` ve `ClickFix-Webhook-Signature: v1=…` başlıklarını taşır. Doğrulama: ham gövde üzerinde `hex(HMAC-SHA256(secret, timestamp + "." + ham_gövde))`, sabit zamanlı karşılaştırma, 5 dakika tolerans, `ClickFix-Webhook-Id` ile tekilleştirme; sonra `2xx`. Başarısız teslimatlar artan aralıklarla 24 saate kadar tekrarlanır. Olay listesi ve gövde biçimi: [Webhook'lar](/docs/webhooks).

		Data struct {
			Secret string `json:"secret"` // yalnız bu yanıtta döner

		if err != nil {
			w.WriteHeader(http.StatusBadRequest)
			return
		}
		if err := clickfix.VerifyWebhook(secret, r.Header.Get("ClickFix-Webhook-Timestamp"),
			r.Header.Get("ClickFix-Webhook-Signature"), raw, time.Now(), 5*time.Minute); err != nil {
			w.WriteHeader(http.StatusUnauthorized)
			return
		}
		// ClickFix-Webhook-Id ile tekilleştirin, kaydedin, sonra 2xx dönün.
		var event struct {
			Event string `json:"event"`
		}
		_ = json.Unmarshal(raw, &event)
		fmt.Printf(`{"received":%q}`+"\n", event.Event)
		w.WriteHeader(http.StatusOK)
	})
	port := os.Getenv("PORT")
	if port == "" {
		port = "3000"
	}
	fmt.Println("listening")
	return http.ListenAndServe("127.0.0.1:"+port, nil)
}

## 9. Mobil: oturumu taşıyan güvenli webview [#mobile]

Mobil uygulamalar için yol, ayrı bir yerel SDK değil, **oturumu taşıyan güvenli bir webview**'dir: uygulama `https://getclickfix.com/widget-embed.html?widget=WIDGET_ID` sayfasını bir webview'de açar; widget tam ekran açılır ve uygulamayla **köprü** üzerinden konuşur. Böylece Flutter, React Native, iOS, Android ve diğer her platform aynı yolla, aynı sözleşmeyle bağlanır. Köprü sözleşmesinin tamamı (mesaj adları, alanlar, hata kodları, güvenlik kuralları) ayrı belgededir: [Webview köprüsü](https://github.com/ClickSolveMainTR/clickfix-app-go/blob/main/docs/webview-bridge.md).

### Oturum devri [#mobile-session]

1. Uygulama, kendi sunucunuzdan `{ user_id, user_hash }` alır ([kimlik doğrulama](#identity)); anahtar uygulamaya hiç inmez.
2. Webview `widget-embed.html?widget=WIDGET_ID&locale=tr&theme=auto` adresini açar. Widget hazır olunca köprüden `{"type":"clickfix:ready", ...}` gelir.
3. Uygulama `{"type":"clickfix:identify","id":"1","user":{"user_id":"1001","user_hash":"…","name":"…","company":{"id":"F-77"}}}` gönderir; cevap `{"type":"clickfix:result","id":"1","ok":true}` olur. Reddedilirse `ok:false` ve `error.code` (`WIDGET_IDENTITY_INVALID` gibi) döner; kullanıcı anonim kalır.
4. Çıkışta `{"type":"clickfix:reset"}` gönderin; ziyaretçi unutulur, sonraki açılış yeni ziyaretçidir.

Webview'in çerez ve depolaması oturumu sayfa yenilemeleri arasında taşır; `reset` göndermeden hesap değiştirmeyin.

**Yerel çekirdekle oturum devri (CF-201).** Uygulama widget uçlarını webview olmadan da çağırabilir: Web widget → Gelişmiş → **Mobil uygulamalar** bölümünde platform ve paket adıyla bir **uygulama anahtarı** oluşturun; `@getclickfix/visitor-core` paketi `mode: "app"` ile bu anahtarı `X-ClickFix-App-Key` ve `X-ClickFix-App-Package` başlıklarında gönderir, sayfa kaynağı gerekmez. Yerel oturumu webview'e `{"type":"clickfix:session","token":client.getToken()}` komutuyla devredin; widget de `ready`, `identify` ve `reset` sonrasında `clickfix:session` mesajıyla kendi belirtecini verir (`client.adoptToken`). Anahtar yalnızca oluşturulduğunda gösterilir ve panelden iptal edilir; `user_hash` doğrulaması tarayıcıdakiyle aynıdır.

### Köprü: uygulamadan widget'a ve widget'tan uygulamaya [#mobile-bridge]

Uygulama → widget (komutlar): `clickfix:identify`, `clickfix:track` (uygulama olayını ekran bağlamına ekler), `clickfix:open` (`view` ya da `conversation`), `clickfix:close`, `clickfix:update` (dil, tema, profil, öznitelik), `clickfix:consent`, `clickfix:reset`, `clickfix:get-state`. Her komut isteğe bağlı bir `id` taşır; `id` varsa widget `clickfix:result` ile cevap verir. Komut `window.ClickFixBridge.receive(json)` çağrısıyla ya da sayfaya `postMessage` ile ulaşır.

Widget → uygulama: `clickfix:ready`, `clickfix:event` (her SDK olayı: `message`, `unread`, `close`, `conversation:ended`…), `clickfix:link` (dışarı açılacak bağlantı; sistem tarayıcısında açın) ve `clickfix:result`. Taşıma, platforma göre widget'ın kendisi tarafından seçilir: `ReactNativeWebView.postMessage`, iOS `webkit.messageHandlers.ClickFix`, Android `ClickFixAndroid` arayüzü, Flutter `ClickFixFlutter` kanalı.

Aşağıdaki uygulama tarafı örnekleri köprüyü kurar, hazır olunca oturumu devreder, uygulama olayı gönderir ve widget'ın `close` olayında destek ekranını kapatır. Bunlar kılavuzun otomatik testine girmez; kendi projenizde derleyip doğrulayın.

// react-native-webview: onMessage widget'tan, injectJavaScript widget'a.
import { useRef } from "react";
import { Linking } from "react-native";
import { WebView } from "react-native-webview";

export function Support({ onClose }: { onClose: () => void }) {
  const ref = useRef<WebView>(null);
  const send = (m: object) =>
    ref.current?.injectJavaScript(
      `window.ClickFixBridge && window.ClickFixBridge.receive(${JSON.stringify(JSON.stringify(m))}); true;`,
    );
  return (
    <WebView
      ref={ref}
      source={{
        uri: "https://getclickfix.com/widget-embed.html?widget=WIDGET_ID&locale=tr",
      }}
      originWhitelist={["https://getclickfix.com"]}
      onShouldStartLoadWithRequest={(r) =>
        r.url.startsWith("https://getclickfix.com/")
      }
      sharedCookiesEnabled={false}
      onMessage={async (e) => {
        const data = JSON.parse(e.nativeEvent.data);
        if (data.type === "clickfix:ready") {
          const s = await api.supportSession(); // { user_id, user_hash } sunucunuzdan
          send({
            type: "clickfix:identify",
            id: "login",
            user: { user_id: s.user_id, user_hash: s.user_hash },
          });
          send({
            type: "clickfix:track",
            name: "app_screen",
            properties: { screen: "orders" },
          });
        } else if (data.type === "clickfix:link") Linking.openURL(data.url);
        else if (data.type === "clickfix:event" && data.event === "close")
          onClose();
      }}
    />
  );
}

// WKWebView: mesaj işleyici adı "ClickFix"; komutlar evaluateJavaScript ile gider.
final class SupportViewController: UIViewController, WKScriptMessageHandler, WKNavigationDelegate {
    private lazy var webView: WKWebView = {
        let config = WKWebViewConfiguration()
        config.userContentController.add(self, name: "ClickFix")
        config.websiteDataStore = .default() // oturum açılışlar arasında kalır; çıkışta clickfix:reset gönderin
        let w = WKWebView(frame: .zero, configuration: config)
        w.navigationDelegate = self
        return w
    }()

    override func viewDidLoad() {
        super.viewDidLoad()
        view = webView
        webView.load(URLRequest(url: URL(string: "https://getclickfix.com/widget-embed.html?widget=WIDGET_ID&locale=tr")!))
    }

    func send(_ message: [String: Any]) {
        let json = try! JSONSerialization.data(withJSONObject: message)
        let literal = String(data: try! JSONSerialization.data(withJSONObject: [String(decoding: json, as: UTF8.self)]), encoding: .utf8)!
        webView.evaluateJavaScript("window.ClickFixBridge && window.ClickFixBridge.receive(\(literal)[0])")
    }

    func userContentController(_ c: WKUserContentController, didReceive m: WKScriptMessage) {
        guard let text = m.body as? String, let data = text.data(using: .utf8),
              let msg = try? JSONSerialization.jsonObject(with: data) as? [String: Any] else { return }
        switch msg["type"] as? String {
        case "clickfix:ready":
            api.supportSession { s in // { user_id, user_hash } sunucunuzdan
                self.send(["type": "clickfix:identify", "id": "login", "user": ["user_id": s.userId, "user_hash": s.userHash]])
            }
        case "clickfix:link":
            if let url = URL(string: msg["url"] as? String ?? "") { UIApplication.shared.open(url) }
        case "clickfix:event" where msg["event"] as? String == "close":
            dismiss(animated: true)
        default: break
        }
    }

    func webView(_ w: WKWebView, decidePolicyFor a: WKNavigationAction, decisionHandler: @escaping (WKNavigationActionPolicy) -> Void) {
        decisionHandler(a.request.url?.host == "getclickfix.com" ? .allow : .cancel) // başka adres webview'de açılmaz
    }
}

        }, "ClickFixAndroid")
        web.loadUrl("https://getclickfix.com/widget-embed.html?widget=WIDGET_ID&locale=tr")
    }

    private fun send(m: JSONObject) =
        web.evaluateJavascript("window.ClickFixBridge && window.ClickFixBridge.receive(${JSONObject.quote(m.toString())})", null)

    private fun onBridge(m: JSONObject) = when (m.optString("type")) {
        "clickfix:ready" -> lifecycleScope.launch {
            val s = api.supportSession() // { user_id, user_hash } sunucunuzdan
            send(JSONObject().put("type", "clickfix:identify").put("id", "login")
                .put("user", JSONObject().put("user_id", s.userId).put("user_hash", s.userHash)))
        }
        "clickfix:link" -> startActivity(Intent(Intent.ACTION_VIEW, Uri.parse(m.getString("url"))))
        "clickfix:event" -> if (m.optString("event") == "close") finish() else Unit
        else -> Unit
    }

### Derin bağlantı [#mobile-deep-link]

- **Belirli bir konuşmayı açmak:** sayfayı `…/widget-embed.html?widget=WIDGET_ID&conversation=KONUSMA_UUID` ile açın ya da açık webview'e `{"type":"clickfix:open","conversation":"KONUSMA_UUID"}` gönderin. Sekme için `view` (`home`, `messages`, `help`, `new`).
- **Bildirimden konuşmaya:** uygulamanızın kendi anlık bildirimi için `message.sent` webhook olayına abone olun; olay `conversation_uuid` ve `contact_external_id` taşır. Bildirimin derin bağlantısı (`uygulamam://destek?conversation=…`) açılınca webview'i yukarıdaki adresle açın. Okunmamış rozeti için widget'ın `unread` olayı (`clickfix:event`) yeterlidir.
- **Widget'tan dışarı:** yardım makaleleri ve mesajlardaki bağlantılar `clickfix:link` olarak gelir; sistem tarayıcısında açın. Webview içinde `getclickfix.com` dışına gezinmeye izin vermeyin.

### Güvenlik notları [#mobile-security]

- **Kimlik anahtarı uygulamaya girmez.** `user_hash` sunucunuzdan, kimliği doğrulanmış bir uçtan gelir; uygulamada hesaplanmaz, sabitlenmez.
- **Kaynak kısıtı:** webview yalnız `https://getclickfix.com` (ya da size verilen uygulama adresi) yükler; başka adrese gezinme engellenir, `clickfix:link` ile gelen adres uygulamada yeniden doğrulanıp (yalnız `https:`) sistem tarayıcısında açılır, intent ya da derin bağlantı işleyicisine verilmez. Üçüncü taraf çerez ve paylaşılan çerez depolarını kapatın; dosya ve içerik erişimini (`allowFileAccess`, `allowContentAccess`) kapatın.
- **JS köprüsü:** `window.ClickFixBridge.receive` yalnız bu sayfada vardır; sayfa ClickFix'e aittir. Köprü, `postMessage` ile gelen iletileri çerçeve içindeyken yalnız yapılandırılmış üst kaynaktan (`boot({ bridge: { origin } })`), çerçeve dışındayken yalnız sayfanın kendisinden kabul eder; `"*"` kabul edilmez. Reddedilen komutlarda ileti içeriği (örneğin `user_hash`) ne konsola ne sonuca yazılır.
- **Çerez ve depolama:** oturum webview'in depolamasında kalır; hesap değişiminde ve çıkışta `clickfix:reset` gönderin. Cihaz paylaşımlıysa webview depolamasını da temizleyin.
- **Onay:** uygulamanız onay topluyorsa adrese `consent=1` ekleyin ya da `clickfix:consent` gönderin; onaysız hiçbir şey saklanmaz.

Flutter paketi `clickfix_webview` (`sdks/flutter/clickfix_webview`; `ClickFixWebView` + `ClickFixController`, köprü sözleşmesi v1, kaynak kilidi, derin bağlantı) ilk sürümünde CI'daki `sdk-publish` işiyle pub.dev'e yayımlanacaktır; o zamana kadar `pubspec.yaml` içinde git bağımlılığı olarak kullanın: `clickfix_webview: { git: { url: https://github.com/ClickSolveMainTR/clickfix-app-go.git, path: sdks/flutter/clickfix_webview, ref: main } }`. Yerel Dart istemcisi (`clickfix_visitor`) ve diğer yerel SDK'lar ayrı işlerdir; çıktıklarında aynı köprü sözleşmesini kullanacaklardır.

## Laravel paketi [#laravel]

Laravel 10, 11, 12 ve 13 (PHP 8.1+) için [`clickfix/laravel`](https://packagist.org/packages/clickfix/laravel) bu kılavuzdaki adımları tek pakette toplar: servis sağlayıcı ve `ClickFix` facade'ı, `config/clickfix.php`, artisan komutları, imzayı doğrulayan `POST /clickfix/webhook` rotası ve her olay için bir Laravel event'i, `@clickfixWidget` Blade direktifi. Paket keşfi sağlayıcıyı kendisi kaydeder. Kaynak ve değişiklik günlüğü: [`clickfix-laravel`](https://github.com/ClickSolveMainTR/clickfix-laravel).

### Kurulum [#laravel-install]

```sh
composer require clickfix/laravel
php artisan clickfix:install
php artisan clickfix:check
```

`clickfix:install` `config/clickfix.php` dosyasını yayımlar, `.env` dosyasına eksik `CLICKFIX_*` anahtarlarını ekler (webhook sırrını üretir), abone olunacak webhook adresini ve sonraki adımları yazar. Anahtarları doldurduktan sonra `clickfix:check` API anahtarını API'ye karşı dener, widget kimliğini, kimlik anahtarını, webhook sırrını ve rotanın `https` olduğunu doğrular; bir şey eksikse çıkış kodu 1'dir.

| `.env` anahtarı            | Nereden                                                                                      |
| -------------------------- | -------------------------------------------------------------------------------------------- |
| `CLICKFIX_API_KEY`         | [Başlamadan önce](#before-you-start) tablosundaki API anahtarı                               |
| `CLICKFIX_WIDGET_ID`       | Web widget → Kurulum                                                                         |
| `CLICKFIX_IDENTITY_SECRET` | Web widget → Güvenlik → Kimlik doğrulama; yalnız sunucuda kalır                              |

### Artisan komutları [#laravel-artisan]

| Komut                                                               | Ne yapar                                                                                                                                      |
| ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `clickfix:install [--force] [--no-env]`                             | Config yayımlar, `.env` anahtarlarını ekler, webhook sırrı üretir, webhook adresini yazar                                                     |

### Widget ve kimlik doğrulama [#laravel-widget]

```blade
    @clickfixWidget
</body>
```

Direktif kuyruk parçacığını, `ClickFix("boot", {...})` çağrısını ve `widget.js` etiketini basar. Argümansız kullanımda oturum açmış kullanıcı doğrulanır (`user_id` model anahtarı, `user_hash` kimlik anahtarıyla sunucuda hesaplanır, `name` ve `email` modelden); kimse oturum açmamışsa widget anonim açılır. `@clickfixWidget($musteri)` belirli bir modeli, `@clickfixWidget(null)` her zaman anonim widget'ı, `@clickfixWidget(auth()->user(), ['locale' => 'tr'])` ek başlatma seçeneklerini verir. Kimliğe giren alanlar `clickfix.widget.user` ile ya da modelde `ProvidesClickFixIdentity` arayüzüyle (`company`, `attributes` dahil) belirlenir.

Inertia, Livewire veya widget'ı kendisi başlatan bir SPA için kimlik yükünü sunucuda üretip sayfaya paylaşın:

```php
use ClickFix\Laravel\Facades\ClickFix;

ClickFix::userHash($user);  // hex HMAC-SHA256(kimlik anahtarı, model anahtarı)
ClickFix::identity($user);  // ['user_id' => '42', 'user_hash' => '…', 'name' => …, 'email' => …]
```

Tarayıcıda `ClickFix("identify", identity)` çağırın; kimlik anahtarı sunucudan çıkmaz ([kimlik doğrulama](#identity)).

### Webhook [#laravel-webhook]

Paket `POST /clickfix/webhook` rotasını `web` grubunun dışında (oturum ve CSRF yok) ve `clickfix.webhook` middleware'i arkasında kaydeder. Middleware `ClickFix-Webhook-Timestamp` ve `ClickFix-Webhook-Signature` başlıklarını ham gövde üzerinde doğrular ([Webhook'lar](#webhooks) bölümündeki kuralla; 5 dakika tolerans, sabit zamanlı karşılaştırma); bozuk veya bayat imza `401`, sır tanımsızsa `503` döner. Aynı `ClickFix-Webhook-Id` ile gelen tekrar teslimat önbellekten tanınır ve olaylar ikinci kez tetiklenmeden `200` ile yanıtlanır.

Doğrulanan her teslimat `ClickFix\Laravel\Events\WebhookReceived` olayını, tanınan olay adları ayrıca kendi sınıfını tetikler: `ConversationCreated`, `ConversationResolved`, `MessageReceived`, `MessageSent`, `ContactCreated`, `ContactUpdated`, `CompanyUpdated`, `SlaBreached`, `CsatSubmitted` … (olay başına bir sınıf; tanınmayan ad yalnız `WebhookReceived`).

```php
use ClickFix\Laravel\Events\MessageReceived;
use Illuminate\Support\Facades\Event;

Event::listen(MessageReceived::class, function (MessageReceived $event) {
    $event->get('conversation_uuid');
    $event->get('contact_external_id'); // sizin kullanıcı numaranız
    $event->payload->occurredAt();      // Carbon
});
```

`CLICKFIX_WEBHOOK_QUEUE=true` (veya bir kuyruk adı) ile olaylar istek yerine `ProcessWebhook` işinden tetiklenir ve rota `202` döner. Rotayı kendiniz tanımlamak için `CLICKFIX_WEBHOOK_ROUTE=false` yapıp kendi rotanıza `clickfix.webhook` middleware'ini ekleyin. Abonelik açma örneği için [Webhook'lar](#webhooks).
